01 About

I run IT for a small organisation, which means security problems land on my desk for real: a hijacked Microsoft 365 account, a firewall under constant attack, a network that kept going down. Working them end to end is what pulled me toward security operations.

I enjoy the detective part: reading sign-in and firewall logs, finding the root cause, and writing down what happened so it does not happen twice.
